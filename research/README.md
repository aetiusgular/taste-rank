# research/

P1 notes. The starting brief is not in this repo: P1 reads it from forge (`briefs/<code>.md`, code from `.forge/state.json`) and re-verifies every claim in it. `P1.md` is the phase's output: product surface, have/lack table, competitor comparison, the three scored candidates and the pick.

Every claim carries a URL (or repo file and line) and the date it was read. Licences are recorded here before any code or data is reused.
